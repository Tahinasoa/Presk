# KTimer (`core/src/timer/`)

`KTimer` is a lightweight, zero-dependency timeline and time management engine for deterministic animation, progress tracking, seeking, and tween scheduling.

---

## 🌟 Key Features

1. **Second-based Precision**: All timeline values (progress, start time, end time, seek position) are measured in **seconds**.
2. **Deterministic Property Tweens (`KTween`)**: Register `KTween` instances generated by `KObject.getTweens()`. The timer initializes and renders them in timeline order, reversing that order during backward seeks.
3. **Playback Control**: Supports `play()`, `pause()`, and `seek(time)` with automatic delta-time advancement via `requestAnimationFrame`.
4. **Seek / Rewind**: Tweens restore their earlier values when the timeline is scrubbed backwards.

---

## 📖 API Usage Example

```ts
import KObject from "@/primitives/kobject/kobject";
import KTimer from "./ktimer";

const timer = new KTimer();

// Register a tween generated by a KObject
const hero = new KObject({ id: "hero", x: 0, y: 0 });
timer.addTweens(hero.getTweens(
  { x: 100 },
  { id: "hero-move", startTime: 0, duration: 2 },
));

// Start the timer loop
timer.play();

// Pause the timer
timer.pause();

// Seek directly to 1.5 seconds
timer.seek(1.5);
```

## 📁 Files in Module

- **`ktimer.ts`**: Core `KTimer` engine for scheduling and rendering `KTween` instances.
- **`ktimer.test.ts`**: Comprehensive unit tests covering progress, pauses, delays, seeks, and tween callbacks.
- **`ktimer.live.ts`**: Real-time Node CLI script demonstrating live clock progress, pauses, and seeks.
