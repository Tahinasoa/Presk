## Presk
Presk is a project that allows pedagogical animations to be described using a declarative language, designed to be reliably generated by an AI rather than hand-coded.
The goal is to make the creation of educational animations (grammar, physics, mathematics lessons, etc.) as simple as describing the scene in natural language to an AI, without having to tinker with SVG or low-level animation code.

⚠️ Status: Project in the design phase. The language specification is still under active iteration.

## Project Structure
The project is composed of three distinct parts:
## language/
Defines the DSL (Domain Specific Language): the grammar, the JSON format, and the full specification of the language used to describe an animation (objects, properties, timing, expressions, anchoring, etc.).
## core/
Contains the engine: the DSL parser, the resolution of expressions and dependencies, timeline management, and rendering. This is what executes a file written in the language defined in language/.
## lib/
Contains the pre-built component libraries, organized by domain (for example: electrical circuits, French grammar, geometry...). These components make it possible to describe a scene at a semantic level rather than drawing each element by hand.
## Why This Project
Most existing tools used to generate pedagogical animations via AI (Manim, imperative code, raw SVG) produce code that is difficult to validate and fix reliably. Presk aims for the opposite: a strict, unambiguous format with ready-to-use business components, allowing an AI to generate correct animations repeatably.
